Architecture & Multi-Agent Dispatch

Automated B2B group chat booking and dispatch system for an enterprise luxury ground transport client in Dubai, extended to an independent musician community routing gateway.

  • Connection Layer: Built in Go using the whatsmeow protocol library for direct session management without official Business API costs.
  • Multi-Agent System: Google ADK orchestrator, booking sub-agent (Google Maps, flight tracking, fare estimation), and support sub-agent.
  • Flight Data Microservice: Independent Cloud Run flight lookup service.
