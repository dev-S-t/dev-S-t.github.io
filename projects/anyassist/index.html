System Overview

Self-service "chat with your data" SaaS platform. Users upload documents to generate a personalized AI agent isolated per tenant, guaranteeing one tenant's data is never reachable from another session.

Engineering Highlights

  • Google ADK Agent Hierarchy: Agent-per-tenant architecture built on Google Agent Development Kit.
  • LiteLLM Gateway Layer: Handles cross-provider model routing, rate limiting, and per-tenant cost attribution. Moving a tenant between LLM providers is a zero-rebuild config change.
  • Logical Vector Isolation: Shared vector storage partitioned via strict namespace boundaries, keeping indices completely isolated.
