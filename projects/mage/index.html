System Overview

MAGe bridges the gap between trend discovery and finished brand video creative. Discovers what content is currently working in a client's niche and turns approved concepts into on-brand video assets automatically.

Architecture & Specialized Agents

  • Brand Extraction: Playwright-driven crawler scrapes client websites (typography, logos, color palette, product shots), feeding a multimodal vision model to compile a persistent brand profile.
  • Agent Hierarchy:
    • Creative Director: Generates distinct creative directions aligned with brand profile.
    • Script Writer: Formats directions into shot-by-shot scripts matched to video model limits.
    • Reference Selector: Maps visual brand assets to script scenes.
    • Dialogue & Voice: Selects and times Cartesia TTS voices against script frames.
    • Video Generator: Segments scripts, generates video via Google Veo, stitches with FFmpeg, and passes final frames as visual anchors for smooth cut transitions.
    • Reviewer Agent: Validates assembled video against script for continuity.
  • Trend Intelligence: Subreddit sentiment and audience engagement scanner providing live signal to Creative Director.
  • Real-Time Accounting: Python `contextvars` session metering tracking LLM tokens, image renders, video seconds, and TTS characters under high async concurrency.
  • Interface: React/Next.js guided decision UI maintaining session state across tab reloads.
