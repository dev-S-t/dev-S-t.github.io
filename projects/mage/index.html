Multi-Agent Media Pipeline

Automated creative advertising and video generation engine designed for businesses without dedicated social media managers.

  • Brand Profiler: Playwright headless website crawler + multimodal vision model extracting typography, colors, logos, and voice.
  • Agent Hierarchy: Creative Director, Script Writer, Reference Selector, Cartesia Voice Agent, Google Veo Video Generator, and Reviewer Agent.
  • Frame Continuity: FFmpeg segment stitching carrying final frame forward as visual anchor for subsequent cuts.
  • Trend Signal: Subreddit sentiment scanner pulling live post ideas.
  • Cost Metering: Session-level real-time token/render cost accounting via Python contextvars.
