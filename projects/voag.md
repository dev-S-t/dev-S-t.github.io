# VOAG — Enterprise Voice AI SaaS

- **Author / Lead:** Sahil Tomar (dev-S-t)
- **Key Metrics:** 1,000+ daily calls, sub-200ms p95 latency
- **Special Deployment:** UAE telephony bridge inside private VM behind strict NAT gateways

## Technical Architecture
VOAG is an enterprise Voice AI SaaS platform engineered for low-latency voice interaction. It bridges WebRTC/SIP telephony with streaming STT, LLM inference, and TTS audio generation. The system operates seamlessly under strict network environments including enterprise NAT gateways.
