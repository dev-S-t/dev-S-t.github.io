System Overview & Production Metrics

  • Scale: 1,000+ voice calls processed daily live inside the Mr. LADs application since January.
  • Latency: Sub-200ms p95 audio pipeline latency.
  • Client Use Cases: Higher-education consultancy (natural unhurried follow-up), real estate (persistent cold calling), travel agency (Dubai B2B partnership outreach).

Infrastructure & Multi-Region Routing

  • Deployments: Main LiveKit server self-hosted on DigitalOcean (India). Secondary UAE client deployment: SIM card into modem into SIP gateway into LiveKit server on local LAN behind strict NAT gateways.
  • Routing & Worker Architecture: Main server routes calls by originating number and tenant ID to regional low-latency workers (India/UAE). 3 additional bulk-handling workers run on GCP Cloud Run with auto-scaling and scale-to-zero, woken via async polling layer. Fully automated GitHub Actions CI/CD with Docker containers.
  • Multi-Provider Model Layer: Gemini Realtime, Sarvam (Indian regional languages, low cost), Ultravox. Dynamic routing based on language, cost, or latency specs.
  • Mid-Call Document Retrieval: Fire-and-forget Google File Search (RAG) integrated directly into Gemini API calls. Results land mid-call without conversation pauses or caller disruption. Admin UI allows folder activation per agent.
  • Testing Playground: Production-identical pipeline simulator minus SIP connection for safe iteration.
