Production Voice Infrastructure

High-throughput Voice AI SaaS platform handling over 1,000 production calls daily in the Mr. LADs app with sub-200ms p95 latency.

  • Infrastructure: Self-hosted LiveKit on DigitalOcean (India) + UAE local LAN SIP modem deployment (SIM ➡️ modem ➡️ SIP gateway ➡️ LiveKit on local LAN behind NAT).
  • Worker Scaling: VM-hosted API & batch manager paired with 3 Cloud Run auto-scale workers (scale-to-zero).
  • Multi-Provider LLM/TTS: Dynamic routing across Gemini Realtime, Sarvam, and Ultravox.
  • Fire-and-Forget RAG: Google File Search RAG returning context without stalling streaming audio loops.
