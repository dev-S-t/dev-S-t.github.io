System Overview

A real-time attention tracking system built to measure video audience engagement metrics live.

Engineering Highlights

Uses client-side computer vision models running directly in the browser via WebAssembly/WebGPU, preserving user privacy by calculating attention heatmaps on-device without streaming raw video to servers.
