System Overview

A real-time AI interview platform where a photorealistic video avatar conducts interviews live. Powered by Gemini Realtime audio-native models for multi-lingual understanding (English and Arabic production requirements) with sub-second language switching.

Engineering Highlights & Deployments

  • LiveKit Self-Hosted GCP Deployments:
    • GCP VM: Baseline production deployment.
    • Cloud Run: Custom container configuration overcoming Cloud Run scale-to-zero model for persistent WebRTC connections.
    • Client Private Server: Overcame untrusted IP range restrictions by deploying custom LiveKit build integrated with ZeroSSL certificates.
  • Multi-LLM Fallback Chain: If primary Gemini Live connection degrades mid-interview, automated failover routes traffic to Groq or Ultravox to prevent interview drops.
