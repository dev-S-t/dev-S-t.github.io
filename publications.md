# IEEE Publication — Sahil Tomar (dev-S-t)

- **Title:** *A Demand-Driven Software Approach with Dynamic Micro-Expiry and Just-in-Time Processing to Reduce Platelet Wastage in Blood Banks*
- **Publisher / Venue:** IEEE
- **IEEE Document Link:** https://ieeexplore.ieee.org/document/11584332
- **Author Contribution (Sahil Tomar):** Ideation, problem formulation, SARIMA/XGBoost model development, and simulation software execution.

## Key Metrics & Validated Results
- **Simulated Platelet Wastage:** Decreased from 11.2% to 2.5% (~78% relative reduction).
- **Demand Fulfillment:** 99.1% maintained across 30 simulation runs.
- **SARIMA Accuracy:** Lowest MAE (5.85) among tested models.
- **Statistical Significance:** Paired t-tests (p < 1.22×10⁻¹²).
